# Group Theory & the 2x2 Rubik's Cube

A long-running, self-paced course on how **group theory derives Rubik's cube algorithms**, taught interactively with an AI tutor.

## How to resume on any machine

1. `git pull`
2. Open this folder in VS Code, start a fresh Copilot chat
3. Say something like: *"continue the group theory course"* — the AI reads `AGENTS.md` + `PROGRESS.md` and picks up where you left off.

## Files

- **[AGENTS.md](AGENTS.md)** — bootstrap instructions for the AI tutor (read first)
- **[SYLLABUS.md](SYLLABUS.md)** — full 15-lesson plan
- **[PROGRESS.md](PROGRESS.md)** — progress table + session history
- **lessons/** — archived full lesson content
- **exercises/** — exercises and solutions
- **code/** — programming implementations (Module 4)

## End-of-session checklist

```
git add -A && git commit -m "progress: <what was covered>" && git push
```
