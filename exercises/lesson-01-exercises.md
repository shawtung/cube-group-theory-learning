# Lesson 1 Exercises — What is a Group?

> Judge whether each is a group. Verify the four axioms (closure, associativity, identity, inverse) and note whether it's Abelian.

**Q1**: The set $\{1, -1\}$ with ordinary multiplication. Is it a group? Verify all four axioms.

**Q2**: The set $\{0, 1, 2, 3\}$ with addition mod 4 (i.e. $a + b \bmod 4$). Is it a group? If so, which earlier example does it "look the same as" (isomorphic to)?

**Q3** (cube intuition): Consider a 2x2 cube where only the R move is allowed ($R, R^2, R', R^4 = e$). Do these operations form a group under composition? Which earlier example is it isomorphic to?
